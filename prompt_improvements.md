# Prompt Improvements

After the first run, I identified issues with table formatting, meal variety and consistency in following dietary restrictions.

I improved the prompt by adding clearer output formatting instructions, strengthening nutritional balance requirements and introducing explicit allergy-exclusion rules.

I tested reusability by changing the FOR block to a different individual with a peanut allergy, lighter activity level and shorter cooking time. The second configuration generated a customised meal plan while retaining the seven-day structure and output format.
